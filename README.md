## 湖南师范大学 2026年-系统分析与设计-课程 24级软件工程01、02班

本课程参考教材：《开源软件构建技术：理论与实践》教材(电子工业出版社: ISBN 978-7-121-52361-8)，并做了相应调整


## 最大调整与亮点

（1）参考了课堂调研结果，**拟基于[Pi Agent](https://github.com/earendil-works/pi)这一最新、影响力大的开源项目进行“系统分析与设计”学习**

（2）**设计了全新的适合小组协作的作业模式，全部作业线上留痕，不限制Git的线上平台**

（3）Git重新设计实践作业，并基于vscode的Git与GitLens插件的演示学习，增加求职竞争力

（4）讲解Git如何结合AI的session分支与代码回退概念

（5）参考课堂调研结果，包管理将主要基于npm和python的包管理，少量学习maven
